API REST desenvolvida em Java com Spring Boot, voltada ao gerenciamento de postagens e comentários.

**Tecnologias:** Java, Spring Boot, Spring Data JPA, MySQL, Flyway e OpenAPI.

**Conhecimentos aplicados:**
- Arquitetura em camadas
- Controllers, Services e Repositories
- DTOs e validações
- Persistência de dados com JPA
- Tratamento de exceções
- Documentação de APIs

🔗 [Acessar Blog API](https://github.com/Vhs0808/blog-api)

### 🏭 Metal Flow — Java EE e Tomcat

Aplicação web para gerenciamento de operações de produção e estoque, desenvolvida com tecnologias tradicionais do ecossistema Java.

**Tecnologias:** Java EE, Apache Tomcat, Servlets, JSP, JDBC e Maven.

**Conhecimentos aplicados:**
- Desenvolvimento web com Java Servlets
- Utilização de JSP
- Organização em DAO, DTO e Models
- Acesso a dados com JDBC
- Estruturação de aplicação web para Tomcat

🔗 [Acessar Metal Flow](https://github.com/Vhs0808/metal-flow)
